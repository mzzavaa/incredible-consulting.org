**Purpose.** The core of the methodology, described end to end so it can be run independently. For consultants, internal architects, and innovation leads who need a repeatable path from ambition to decision.

**Contains.**
- The premise: a decision is the deliverable, everything else is supporting evidence
- Sequence diagram of the four weeks with the work that happens between sessions
- Entry criteria: what must be true before workshop one is worth booking
- Artefact chain showing how each session's output becomes the next session's input
- Timeboxing rules and what to cut when a session runs long
- Exit criteria and the three legitimate outcomes, including "stop"
- Measurement: how to tell afterwards whether the method worked

**Primary CTA.** Copy the agenda pack and run workshop one with your own team.
