**Purpose.** Turns readers into contributors. For practitioners, other consultancies, and students who have field evidence the library does not yet contain.

**Contains.**
- Four contribution types: correction, field note, new artefact, translation
- Current open calls, the gaps we know about and want filled
- Where the source lives and how to raise an issue or a pull request
- Time expectation per contribution type, honestly stated
- Recognition model: contributor credit on the artefact, no unpaid ghostwriting
- Code of conduct link and enforcement contact

**Primary CTA.** Open an issue with the thing that did not work for you.
