## The services doing the work

Read off the slides, not guessed. Each card says what that service did in this build, and links to the page explaining the capability and how to run it somewhere else.

### Backstage

The CNCF developer portal at the centre of the talk: one template turns an AWS account request into a provisioned account, instead of a service desk acting as a firewall.

### Red Hat OpenShift

The platform the portal runs on in this setup.

### AWS IAM

Account provisioning and the guardrails that come with it, applied the same way every time.
