**Purpose.** The library landing page. It is the main reason most people arrive here, so it has to make the whole collection scannable in under thirty seconds.

**Contains.**
- Filter bar by domain (AI, data, platform, cost, migration) and by maturity (draft, reviewed, stable)
- Card grid rendered from `data/playbooks.yaml`, each card showing title, one-line outcome, effort estimate, and version
- "Start here" callout for the three playbooks that work as an entry sequence
- Format note: every playbook is a markdown file with a printable checklist and an editable worksheet
- Version and changelog line, linking to /about/changelog/
- Reuse terms in one sentence with a link to the full licence page

**Primary CTA.** Pick a playbook and run it, or fork the repository.
**Links to.** /licensing/reuse-terms/, /contribute/, /method/, /architectures/.
