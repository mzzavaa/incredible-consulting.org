**Purpose.** Checklists are the most reused artefact in the library. This page keeps them findable and makes clear that each one is a gate, not a wish list.

**Contains.**
- Table rendered from `data/checklists.yaml` with item count, review stage, and last review date
- Usage note: how to run a checklist as a gate with a named approver
- Printable and machine-readable formats for each checklist, including YAML for pipeline checks
- Scoring guidance: pass, pass with exceptions, fail, and how to record exceptions
- Review cadence and who owns each checklist

**Primary CTA.** Print one checklist and use it in the next go-live review.
**Links to.** /playbooks/, /architectures/, /contribute/review-process/.
